What is the difference between moc3 and cmo3 files?

This page explains the delivery file scope and editability points that often come up before commissioning Live2D rigging.

Live2D Delivery Files

moc3 is for applying the model, cmo3 is the editable source file

A Live2D model is usually used through a moc3-based file set in applications such as VTube Studio. A cmo3 file is closer to the source work file that can be opened and edited in Live2D Cubism Editor.

.moc3A file that can be applied in VTube Studio to run the model.
.cmo3An editable source work file for modifying rigging in Live2D Cubism Editor.
Runtime filesModel files and configuration files needed for use are delivered according to the model structure and work scope.
Source filesEditable source files that contain the rigging workflow and structure are not included in standard delivery.

Dajoong delivers model files prepared for VTube Studio use

Dajoong's standard delivery is based on model files that can be applied in VTube Studio. Editable cmo3 source files are not included in the standard delivery scope and are not provided for general commissions. If rigging changes are needed, please request a revision separately.

Standard Delivery Model files and configuration files needed for VTube Studio setup
Not Included Editable .cmo3 source work file for Live2D Cubism Editor
When Revisions Are Needed Rigging errors are checked and revised, while excessive requests or repeated reversals may incur additional fees.
