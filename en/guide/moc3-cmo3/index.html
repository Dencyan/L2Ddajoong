MOC3 and CMO3 Files: Differences, Uses and Conversion Questions

.cmo3 is a working file for editing a model in Live2D Cubism Editor. .moc3 is model data used by a program. Using a model and editing its original rig require different files.

MOC3 and CMO3 at a glance

.moc3Model data used by a program, together with the required textures and configuration files.
.cmo3An editable working file for opening and changing the rig in Cubism Editor, distinct from files delivered for model use.

What is a MOC3 file used for?

A .moc3 file contains model data for a compatible program. The extension alone does not tell you whether the delivery package is complete.

Running a model requires the files appropriate to its structure and the target program. Dajoong supplies model and supporting files prepared for VTube Studio use.

What is a CMO3 file, and when do you need it?

A .cmo3 file is the working source used to edit the rig in Cubism Editor. This is different from using a delivered model for streaming.

Source-file delivery and permission to make changes depend on the commission agreement with the creator. The Dajoong policy below is not a rule for every rigger.

MOC3 to CMO3: what should you check before editing?

If you are searching for MOC3 to CMO3 conversion, first distinguish running a model from editing its source. Renaming a file extension does not turn it into an editable source file.

This guide does not provide a tool or a verified reverse-conversion procedure for restoring the original .cmo3 from .moc3. For source editing, ask the original creator about source-file availability, delivery terms and the permitted scope of changes.

  • To use the model, check the runtime file package and your target program.
  • To edit the rig, check whether you have the .cmo3 source and permission to modify it.
  • If you do not have the source, send the original creator your available files and the changes you need.

Can you use a model without CMO3?

The .cmo3 editing source is not required simply to use a model when its runtime package is ready. This does not mean that a single .moc3 file is always enough.

Keep the delivered supporting files together, and distinguish files for model use from the source used to edit the rig.

Dajoong delivery files and revision scope

Dajoong normally delivers model and supporting files for VTube Studio. Editable .cmo3 source files are not included and are not provided for standard commissions.

No Live2D Reverse Engineering or Data Extraction
Extracting data from the delivered model files, including reverse engineering Live2D models or reconstructing .cmo3 files, is prohibited.
Modifying, reworking, reselling, renting out, sharing, transferring, or distributing extracted data, as well as commissioning third parties to modify or rework that data, is also prohibited.

Rigging errors are reviewed and corrected. Excessive changes or repeated reversals may incur additional fees. Work on a model made by another creator requires checking the source, permission and scope first.
