Live2D Delivery Files

moc3는 적용 파일, cmo3는 원본 작업 파일입니다

Live2D 모델을 실제 프로그램에서 불러올 때는 보통 moc3 기반 구성 파일을 사용합니다. 반대로 cmo3는 Live2D Cubism Editor에서 리깅 구조를 열고 수정하는 작업 원본에 가깝습니다.

.moc3VTube Studio 등에서 모델을 실행하기 위한 런타임용 모델 파일입니다.
.cmo3Live2D Cubism Editor에서 수정 가능한 원본 작업 파일입니다.
model3.json텍스처, 물리, 표정, 모션 등 모델 구성 파일을 연결합니다.
textures / physics모델 표시와 물리 움직임에 필요한 보조 파일입니다.

Dajoong 기본 납품은 적용 가능한 모델 구성 파일입니다

Dajoong의 기본 납품 범위는 모델 적용에 필요한 moc3 기반 파일입니다. 수정 가능한 cmo3 원본 파일은 기본 제공하지 않으며, 리깅 수정이 필요할 때는 별도로 수정 요청을 주시는 방식으로 확인합니다.

기본 납품 .moc3, model3.json, 텍스처, 물리/표정 등 적용에 필요한 구성 파일
기본 제공 제외 Live2D Cubism Editor에서 수정 가능한 .cmo3 원본 작업 파일
수정이 필요할 때 납품 후 적용 중 발견된 리깅 오류는 확인 후 수정 범위를 안내합니다.

자주 묻는 질문

일반적인 의뢰/사용 흐름에서는 moc3를 cmo3 원본 작업 파일로 되돌려 수정하는 방식으로 보지 않습니다. 수정이 필요하다면 원 작업자에게 요청하는 쪽이 안전합니다.

moc3 단일 파일만으로 끝나지 않고, model3.json, 텍스처, 물리 설정, 표정/모션 파일 등 모델 폴더 전체 구성이 필요할 수 있습니다.

사용 프로그램, 필요한 표정과 소품, iOS 또는 VBridger 옵션 필요 여부, 공개 일정, 납품 후 적용 환경을 미리 정리하면 견적과 작업 확인이 빨라집니다.
