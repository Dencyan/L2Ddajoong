moc3는 적용 파일, cmo3는 원본 작업 파일입니다

Live2D 모델을 실제 프로그램에서 불러올 때는 보통 moc3 기반 구성 파일을 사용합니다. 반대로 cmo3는 Live2D Cubism Editor에서 리깅 구조를 열고 수정하는 작업 원본에 가깝습니다.

.moc3VTube Studio에 적용해 모델을 실행할 수 있는 파일입니다.
.cmo3Live2D Cubism Editor에서 리깅을 직접 수정할 수 있는 원본 작업 파일입니다.
적용 파일모델 실행에 필요한 구성 파일은 모델 구조와 작업 범위에 맞춰 함께 전달됩니다.
수정 원본리깅 작업 방식과 수정 가능한 구조가 포함된 원본 파일은 기본 제공하지 않습니다.

Dajoong 기본 납품은 적용 가능한 모델 구성 파일입니다

Dajoong의 기본 납품은 VTube Studio에 적용해 사용할 수 있는 모델 파일을 기준으로 합니다. 수정 가능한 cmo3 원본 파일은 기본 납품 범위에 포함되지 않으며, 일반 의뢰에서는 제공하지 않습니다. 리깅 수정이 필요할 때는 별도로 수정 요청을 주시는 방식으로 확인합니다.

기본 납품 VTube Studio 적용에 필요한 모델 파일과 구성 파일
기본 납품 제외 Live2D Cubism Editor에서 수정 가능한 .cmo3 원본 작업 파일
수정이 필요할 때 리깅 오류는 확인 후 수정하며, 과도한 수정 요청이나 번복은 추가금이 생길 수 있습니다.

자주 묻는 질문

일반적인 의뢰 및 사용 환경에서는 .moc3 파일을 .cmo3 원본 작업 파일처럼 되돌려 수정하는 방식으로 안내하지 않습니다. 모델 수정이 필요하다면 리깅 작업자에게 수정 가능 여부를 먼저 문의해 주세요.

납품 파일은 VTube Studio에 바로 적용해 사용할 수 있는 형태로 전달됩니다. 다만 세부 트래킹 설정은 사용자의 이목구비와 환경에 맞게 조정하면 더 자연스럽게 사용할 수 있습니다.

.cmo3 파일은 Live2D에서 직접 수정할 때 필요한 원본 작업 파일이므로, 모델을 실행하는 데는 필요하지 않습니다.

.cmo3 원본 파일이 없다면 Live2D에서 직접 리깅을 수정할 수 없습니다. 수정 방법이 있더라도 허가 없는 2차 수정은 금지됩니다.

다른 Live2D 지원 프로그램이 있을 수 있지만, Dajoong이 제공하는 파일과 세팅은 VTube Studio 사용을 기준으로 작업됩니다.
