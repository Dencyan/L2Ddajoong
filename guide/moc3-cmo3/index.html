.cmo3Cubism Editor에서 모델의 리깅 구조를 열고 편집하는 원본 작업 파일입니다. 실행용 납품 파일과 구분됩니다.

moc3 파일은 무엇이며 어디에 사용하나요?

.moc3는 모델을 지원 프로그램에서 불러오는 데 사용하는 데이터입니다. 파일 확장자만으로 납품 묶음이 완전한지는 판단할 수 없습니다.

모델을 실행하려면 모델 구조와 프로그램에 맞는 구성 파일이 필요합니다. Dajoong은 VTube Studio 적용을 기준으로 모델 파일과 구성 파일을 함께 전달합니다.

cmo3 파일은 무엇이며 언제 필요한가요?

.cmo3는 Cubism Editor에서 리깅을 직접 편집할 때 사용하는 작업 원본입니다. 이미 납품된 모델을 방송에서 사용하는 목적과는 구분해야 합니다.

원본의 제공 여부와 수정 허용 범위는 작업자와의 의뢰 조건을 확인해야 합니다. 아래 Dajoong 정책은 모든 리거에게 공통으로 적용되는 규칙이 아닙니다.

moc3 to cmo3: 원본처럼 수정하려면 무엇을 확인해야 하나요?

moc3 to cmo3 변환을 찾고 있다면 먼저 모델을 실행하려는지, 리깅 원본을 수정하려는지 구분하세요. 확장자를 바꾸는 것만으로 편집 원본이 되는 것은 아닙니다.

이 안내는 .moc3를 원래의 .cmo3로 복원하는 프로그램이나 검증된 역변환 절차를 제공하지 않습니다. 원본 편집이 필요하면 작업자에게 원본 보유·제공 여부와 수정 가능 범위를 확인하세요.

  • 모델 사용이 목적이면 실행용 파일 묶음과 사용할 프로그램을 확인합니다.
  • 리깅 편집이 목적이면 .cmo3 원본 보유 여부와 수정 허가를 확인합니다.
  • 원본이 없으면 기존 작업자에게 원하는 수정 내용과 보유 파일을 전달합니다.

cmo3 없이 모델을 사용할 수 있나요?

실행용 파일 묶음이 준비되어 있다면 모델 사용에 .cmo3 편집 원본이 반드시 필요한 것은 아닙니다. 그렇다고 .moc3 파일 하나만으로 항상 바로 사용할 수 있다는 뜻은 아닙니다.

실행에 필요한 파일과 리깅 구조를 편집하는 원본을 구분하고, 전달받은 구성 파일을 함께 보관하세요.

Dajoong의 납품 파일과 수정 요청 범위

Dajoong의 기본 납품은 VTube Studio 적용에 필요한 모델 파일과 구성 파일입니다. 수정 가능한 .cmo3 원본은 기본 납품 범위에 포함되지 않으며 일반 의뢰에서는 제공하지 않습니다.

리깅 오류는 확인 후 수정합니다. 과도한 수정 요청이나 수정 후 번복은 추가금이 발생할 수 있습니다. 다른 작업자의 모델은 원본과 수정 허가 등 작업 조건을 먼저 확인해야 합니다.

모델 사용에는 실행용 모델 파일과 구성 파일이 필요합니다. .cmo3는 리깅 원본 편집을 위한 파일이며, 실행용 파일 묶음이 준비되어 있다면 모델 사용에 필수인 것은 아닙니다.

Dajoong은 일반 의뢰에서 .cmo3 원본을 제공하지 않습니다. 기본 납품은 VTube Studio 적용에 필요한 모델 파일과 구성 파일입니다.

사용 환경에 맞춘 세부 트래킹 조정과 리깅 원본 편집은 다른 작업입니다. 리깅 변경은 작업자에게 문의하고, Dajoong 작업물의 허가 없는 2차 수정은 하지 않아야 합니다.

Dajoong의 납품 파일과 세팅은 VTube Studio 사용을 기준으로 합니다. 다른 프로그램의 호환 여부는 별도로 확인해야 합니다.
